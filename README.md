# NANDAN AI — All In One AI Tools Directory

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

**NANDAN AI** is a modern, responsive, and feature-rich directory of top AI tools, web applications, and services. Designed with a dark mode glassmorphism UI, smooth video background integration, real-time search, category filtering, tool submission workflows, and detailed modal views.

---

## 🌟 Key Features

- **2,400+ AI Tools Cataloged**: Dynamic directory structure categorized into Chatbots, Image Generation, Coding, Writing & SEO, Video Editing, and more.
- **Glassmorphism & Micro-animations**: Sleek, futuristic user interface with responsive CSS backdrop filters and smooth transitions.
- **Live Video Background**: High-definition looping video background (`background.mp4`).
- **Real-Time Interactive Search**: Instant search filtering across tools and descriptions.
- **Category & Pricing Filters**: Seamless filtering by pricing models (*Free*, *Freemium*, *Paid*) and categories.
- **Tool Details & Community Submission**: Interactive modals to view tool details or submit new AI products.
- **Vercel Ready**: Pre-configured with `vercel.json` for zero-configuration instant deployment.

## 🚀 Quick Start (Local Development)

You can run NANDAN AI locally using any standard static file server:

### Option 1: Using Node.js / serve

```bash
npm run dev
# or
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) (or the port output in your terminal) in your browser.

### Option 2: Using PowerShell Server Script

```powershell
.\server.ps1
```

Open [http://localhost:5000](http://localhost:5000) in your browser.

## ☁️ Deployment to Vercel

This repository is ready for continuous deployment on **[Vercel](https://vercel.com/)**.

### Steps to Deploy:
1. Log into your [Vercel Dashboard](https://vercel.com/dashboard).
2. Click **"Add New Project"** and select **"Import Git Repository"**.
3. Choose the `rupamnandan239-bit/NANDAN-AI` repository.
4. Keep all default settings (Framework Preset: **Other / Static**).
5. Click **Deploy**!
